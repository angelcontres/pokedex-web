1. Introducción y Objetivos

El presente informe documenta el desarrollo de una aplicación web moderna y reactiva construida con React 19, TypeScript y Tailwind CSS, cuyo objetivo principal es consumir y presentar datos en tiempo real provenientes de la API pública PokéAPI (v2).

Objetivos de la práctica:

  • Implementar peticiones asíncronas HTTP (GET) a los endpoints de la PokéAPI mediante la función nativa fetch de JavaScript.
  • Optimizar el rendimiento mediante una estructura de caché en memoria (Map) para evitar consultas redundantes.
  • Estructurar una interfaz semántica de dos columnas utilizando las etiquetas HTML5 <main> para el catálogo y <aside> para el panel de filtrado lateral.
  • Facilitar la búsqueda en tiempo real por nombre o número de Pokédex, así como filtros combinados por región/generación y tipo elemental.

3. Arquitectura del Consumo de la API

La aplicación implementa un consumo eficiente en dos fases:

  1. Lista Maestra Inicial: Al cargar, se solicita al endpoint /pokemon?limit=1025 la lista de nombres e IDs para permitir búsquedas instantáneas en el cliente.
  2. Carga por Lotes con Caché: Los detalles individuales de cada Pokémon se consultan en paralelo en bloques de 15 elementos y se guardan en un objeto Map<number, PokemonDetail>, asegurando que cada Pokémon se consulte solo una vez a la red.
// Fragmento de pokeapi.ts: Consulta con memoria caché export async function getPokemonDetail(idOrName: string | number): Promise<PokemonDetail> { const key = typeof idOrName === 'string' ? idOrName.toLowerCase() : idOrName; if (pokemonCache.has(key)) return pokemonCache.get(key)!; const res = await fetch(`https://pokeapi.co/api/v2/pokemon/${key}`); if (!res.ok) throw new Error('No se encontró el Pokémon'); const data = await res.json(); pokemonCache.set(data.id, data); return data; }

5. Conclusiones

  • El consumo de servicios web REST mediante fetch y TypeScript permite construir aplicaciones cliente modernas y altamente escalables que se abastecen de información pública en tiempo real.
  • La integración de una memoria caché en memoria (Map) optimiza drásticamente los tiempos de respuesta de la interfaz, reduciendo peticiones duplicadas y garantizando una experiencia fluida.
  • El uso de maquetación semántica mediante etiquetas de HTML5 (<header>, <main> y <aside>) mejora la estructura del código, la accesibilidad web y permite una distribución espacial intuitiva para el usuario.
